# Decaf · лабораторная работа 1

Лексический и синтаксический анализатор на C++17. Для сборки нужны POSIX shell и компилятор C++17. Переменная окружения `CXX` позволяет выбрать компилятор.

```sh
./build.sh
./run.sh -t scan tests/sum.decaf
./run.sh -t parse tests/sum.decaf
./run.sh -d tests/sum.decaf
python3 tests/check.py
```

В режиме `scan` каждая строка вывода содержит номер строки исходника и лексему. Перед идентификаторами и литералами выводится также категория. Режим `parse` включён по умолчанию. При успехе программа завершается с кодом 0. Ключ `-d` выводит дерево с отступами. При ошибке программа возвращает 1 и пишет диагностику в stderr.

Длинные имена ключей — `--target`, `--debug`, `--output` и `--opt`. Параметр `-o FILE` перенаправляет результат в файл. Параметр `-O LIST` принимает список оптимизаций для совместимости с интерфейсом курса. На первом этапе оптимизации отсутствуют.

Подход к реализации описан в [отчёте](REPORT.md).
