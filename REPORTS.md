# Отчёт по лабораторной работе №1

Реализован лексический и синтаксический анализатор языка Decaf на Java.
Лексер и парсер генерируются ANTLR 4 по грамматике `Decaf.g4`.
Для сборки используется Gradle Wrapper.

## Структура проекта

- `src/main/antlr/Decaf.g4` — правила лексического и синтаксического анализа.
- `src/main/java/decaf/` — запуск анализаторов, аргументы командной строки и обработка ошибок.
- `src/test/java/decaf/` — автоматические тесты на JUnit.
- `examples/` — корректные программы и примеры с ошибками.

## Что сделано

- Лексер распознаёт ключевые слова, идентификаторы, числа, строки, символы и операторы. Пробелы и комментарии пропускаются.
- Парсер разбирает объявления переменных и массивов, функции, вызовы, присваивания, условия, циклы и выражения с приоритетами операций.
- Строится дерево разбора ANTLR. Собственное AST не реализовывалось.
- Ошибки выводятся с именем файла, строкой и столбцом.
- Добавлены режимы сканирования и разбора, вывод дерева и запись результата в файл.


## Как запустить

Нужен JDK, совместимый с Gradle 8.14.3.
При первой сборке нужен интернет для загрузки зависимостей.
Все команды выполняются из корня проекта.

Сборка и тесты:

```sh
./build.sh
```

Проверка программы без вывода при успехе:

```sh
./run.sh examples/minimal.decaf
```

Вывод дерева разбора:

```sh
./run.sh --debug examples/functions.decaf
```

Вывод токенов:

```sh
./run.sh --target scan examples/literals.decaf
```

Запись дерева в файл:

```sh
./run.sh --output build/tree.txt examples/control-flow.decaf
```

Запуск только тестов:

```sh
./gradlew test
```

После изменения исходников нужно повторить `./build.sh`.
Код завершения: `0` — успех, `1` — ошибка анализа или ввода-вывода, `2` — неверные аргументы.
