# Отчёт по проекту

## Структура проекта
- `src/lexer/` — сканер, разбивает исходник на токены.
- `src/parser/` — парсер, строит и проверяет структуру программы.
- `tests/` — тесты.

## Что сделано
- **Лексер**: распознаёт ключевые слова, идентификаторы, числа, строки, символы, операторы, комментарии. Сообщает об ошибках.
- **AST**: описал узлы дерева: выражения, операторы, объявления, методы.
- **Парсер**: проверяет объявления, переменные, `if/for/while`, `return`, вызовы методов, выражения с приоритетами операторов. При ошибке выводит сообщение.
- **Тесты**: позитивные и негативные, подключены через CTest.
